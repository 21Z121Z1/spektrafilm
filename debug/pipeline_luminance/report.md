# 胶片与相纸模拟亮度传递函数审计报告 (Pipeline Luminance Audit)

本报告基于 `spektrafilm` 现有运行管线的分析，量化了从物理场景输入 (Scene-Linear) 到最终输出 (Scan RGB) 的亮度分布演化。

## 1. 核心映射数据 (Key Measurements)

在默认预设 `kodak_portra_400` + `kodak_portra_endura` 下，测试灰阶渐变（Ramp）的核心映射关系如下：

| 物理含义 | `scene_y` (线性) | `look_y` (最终 RGB 输出) |
| --- | --- | --- |
| 18% 中性灰 | 0.184 | **0.4647** |
| 漫反射白 (Diffuse White) | 1.0 | **0.8387** |
| 高光 (+1 EV) | 2.0 | **0.8898** |
| 高光 (+2 EV) | 4.0 | **0.9067** |
| 极高光 (+3 EV) | 8.0 | **0.9103** |
| 极高光 (+4 EV) | 16.0 | **0.9108** |

**观察结论**：
- 相纸的高光滚降（Shoulder）在 `scene_y = 1.0`（漫反射白）之后极度剧烈。
- `scene_y=4.0` 几乎就已经达到了物理极限（0.9067）。
- 绝对上限并不是 `0.8` 或 `1.0`，而是非常精确的 **`0.911`**。

## 2. 亮度传递管线全景图 (Pipeline Map)

1. **`input_rgb` (Scene-Linear)**
   - 范围：[0.0, ∞)
   - 作用：接受真实世界的无界线性光信号。
2. **`preprocessed_rgb` (Post Auto-Exposure)**
   - 范围：被测样本在自动曝光后 `max ≈ 57.2`。
   - 作用：将图像缩放至 `scene_y=1.0` 对齐漫反射白。此阶段仍是纯线性。
3. **`log_raw_film` (Film Exposure)**
   - 范围：[-2.3, +2.4]
   - 作用：将线性光转为对数域曝光度（Log Exposure）。动态范围被压缩为有限的对数档位。
4. **`cmy_film` (Negative Density)**
   - 范围：[-0.01, 2.04] (负片密度)
   - 作用：由胶片的特性曲线（Density Curves）决定，高光被转换为非常高的染料密度（负片的 Dmax）。
5. **`log_raw_print` (Print Exposure)**
   - 范围：[-1.35, 0.85]
   - 作用：负片密度通过放大机（Enlarger）反转投射到相纸上，高密度区变成低曝光。
6. **`cmy_print` (Paper Density)**
   - 范围：[0.000, 2.012]
   - 作用：相纸曝光再次转化为相纸的染料密度。相纸的 `Dmin` 极低，这意味着即使受到再强的光（对于负片则是受极少的光），其密度也降不到绝对的 0。
7. **`rgb_scan` (Output RGB / Reflectance)**
   - 范围：[0.057, 0.911]
   - 作用：扫描仪将相纸密度转回反射率 / RGB 数值。

## 3. Paper White 阈值的来源分析

管线并没有任何一步硬裁剪（Hard Clip）到 `0.8`。最终的极限值 `0.9119` 来自于：
- **相纸的物理 Dmin**：相纸基底并非 100% 反射的绝对白体。其最小密度（Dmin）约为 `0.04`，通过 $10^{-0.04} \approx 0.912$，这就是 `0.911` 极限的物理根源。
- **漫反射白为何是 0.838**：因为放大机和冲洗平衡的目标，是将曝光在 `scene_y=1.0` 的区域印在纸上显得“是一张白纸但不至于完全失去细节”的位置，所以在相纸曲线上落在了 `0.838`。

这个机制非常优美，它完全由物理模拟驱动，是一个极其稳定的状态，不应该在 SDR 中去改动它。

## 4. Paper Shoulder 形状分析

- **肩部位置**：肩部的曲率变化集中发生在 `scene_y` 介于 `1.0` (0.838) 到 `4.0` (0.906) 之间。
- **Logistic 的契合度**：它与现有的 `logistic` 函数完美契合。`k ≈ 5.5` 就是基于 RA-4 相纸化学反应推算出的自然滚降。
- **作为 HDR 映射来源**：现有的 `_apply_rolloff` 中保留了这个形状是极其准确的。在进行 HDR 拓展时，我们**必须借用这种压缩阻尼（Derivate slope decay）**，但绝对不能**继承其上限 (0.911)**，这正是此前实现中将它放在 HDR 无界容器内进行 Graft 的意义。

## 5. 针对下一步 HDR 映射架构的建议

结合真实管线的行为和您的最终目的（将漫反射推向 HDR 域）：

1. **是否需要 HDR Base Lift？**
   **不需要做暴力的全局 Base Lift**。因为那会破坏中性灰 (0.46) 的绝对表现。但在目前的架构中，漫反射白 `1.0` 在 SDR 域只输出 `0.83`。如果在 HDR 下希望让它发光（比如等效 200 nits 或 `2.0`），就需要在 `target_y` 层面对 `1.0` 施加非线性的映射拉抬。
   
2. **漫反射的 HDR 映射点**：
   建议新增 `hdr_diffuse_white_target`（例如 `1.5`）。
   - 让 `scene_y = 1.0` 的部分输出为 `1.5`，而 `scene_y = 0.18` 的部分依然贴合 SDR `0.46`。

3. **Specular 的接管范围**：
   - 目前的 `graft_start = 1.0`，这意味着漫反射和中性灰完全走相纸 SDR（0.83）。如果想让漫反射白变得更亮（ HDR domain ），要么降低 `graft_start` 使得高光侧的曲线提早干预，要么就像上方第二点所说的做曲线重映射。

4. **结论**：
   现有的 HDR paper rolloff 数学框架（`k=5.5` 的 logistic）本身**不需要推倒重来**。但我们需要在 `prepare_hdr_photo_renditions` 中优化 `blend` 和 `SDR base` 之间的合并算法，引入针对漫反射白的高光拓展节点，使其能在“保留暗部胶片感”的前提下，把原本被压死在 `0.911` 以下的高光区重新舒展开，使其自然地伸展向 `max_headroom`。
